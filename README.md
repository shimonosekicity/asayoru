# 朝晩28日メニュー（PWA版）

朝5〜10分・夜25〜50分の習慣づくりアプリです。スマホのホーム画面に追加して使います。

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（見た目） |
| `app.js` | ボタンを押したときの動き・保存・お知らせ・バックアップ |
| `core.js` | 日付の計算、メニュー、動画リスト、カレンダー用ファイルづくり、カロリーの目安・目標の進み具合の計算 |
| `meals.js` | アプリのレシピ（夜ごはん7品の材料・作り方・カロリー）と材料の表 |
| `recipes.js` | 夜ごはんのおすすめに使うネットのレシピ（味の素パーク46品のリンク・カロリーなど） |
| `sw.js` | オフラインでも開けるようにする仕組み（Service Worker） |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加したときの名前とアイコン |
| `tests/` | 日付計算などの自動テスト |
| `tools/` | 動画が公開中かの確認、オフライン動作の確認（開発用） |

公開するときは、このフォルダの中身を**まるごと**アップロードします（`tests/` と `tools/` は入っていても問題ありません）。

## 公開のしかた（GitHub Pages・無料）

パソコンで行います。所要時間は15分くらいです。

1. **GitHubのアカウントを作る**：https://github.com/signup で作成（無料）
2. **置き場所（リポジトリ）を作る**
   - 右上の「＋」→「New repository」
   - Repository name に `asayoru` と入力
   - **Public** を選ぶ（無料プランで公開するには Public が必要です。アップロードするのはアプリの部品だけで、体重などの記録は入りません）
   - 「Create repository」
3. **ファイルをアップロードする**
   - できた画面の「uploading an existing file」をクリック
   - エクスプローラーで `asayoru-app` フォルダを開き、**中身をすべて選んで**ブラウザにドラッグ＆ドロップ（`icons` フォルダごと入れてOK）
   - 下の「Commit changes」をクリック
4. **公開をオンにする**
   - リポジトリの「Settings」→ 左の「Pages」
   - 「Branch」で `main`、フォルダは `/(root)` を選んで「Save」
   - 1〜2分待つと、上に `https://（あなたのユーザー名）.github.io/asayoru/` と表示されます。これがアプリのURLです
5. **スマホで開く**：そのURLをLINEやメールで自分に送り、スマホで開きます

### あとで中身を直したとき
同じリポジトリで「Add file」→「Upload files」から、変えたファイルを上書きアップロードします。
スマホのアプリは、**2回開き直すと**新しい版になります（1回目の起動で裏で新しい版をダウンロードし、2回目から使われます）。

### 別の方法：Netlify Drop
https://app.netlify.com/drop を開いて、`asayoru-app` フォルダをドラッグするだけでも公開できます。
ただし、アカウントを作って「Claim」しないと、しばらくすると消えます。長く使うなら GitHub Pages がおすすめです。

## スマホのホーム画面に追加する

**iPhone**：**Safari** でURLを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
> ⚠ iPhoneでは、Safariで使った記録とホーム画面のアプリの記録は**別々**です。先にホーム画面に追加してから使い始めてください。

**Android**：Chromeで開く →「︙」→「ホーム画面に追加」（または「アプリをインストール」）

## 朝と夜のお知らせ（いちばん大事なところ）

### えらんだ方法：スマホのカレンダーに予定として入れる（.icsファイル）

アプリの「設定・お知らせ・バックアップ」→ 時刻を選ぶ →「カレンダーに追加する」。
これから8週間ぶん、毎日の朝・夜に**その日のメニュー名つき**の予定（例：「☀ 朝：朝ヨガ＋姿勢リセット（約10分）」）が入り、時刻になるとカレンダーが知らせてくれます。8週間たつ前に、アプリが「続きを追加しましょう」と声をかけます。

**なぜWebの通知（プッシュ通知）にしなかったか**

- iPhone（iOS 16.4以降）では、ホーム画面に追加したWebアプリなら通知を受け取れます。ただし、それは**サーバーから送る「プッシュ通知」だけ**です。「毎朝7時に出す」ような、スマホの中で予約する通知の仕組みは、iPhoneのSafariにもAndroidのChromeにもありません（Chromeで試験的に作られた「Notification Triggers」という仕組みは、正式な機能にならずに終わりました）。
- 決まった時刻にプッシュを送るには、24時間動くサーバーが必要です。無料の方法（GitHub Actionsの定期実行など）は、**数分〜数十分遅れたり、混雑時に実行されなかったり**することがあり、「確実に届く」とは言えません。さらに、通知を送るための鍵の管理など、初心者には手間とリスクが増えます。
- スマホのカレンダーのお知らせは、OSそのものの機能なので、**電波がなくても、アプリを開いていなくても、時刻どおりに鳴ります**。

### 端末ごとの入れ方

**iPhone**
- ホーム画面のアプリから「カレンダーに追加する」を押すと「リンクをコピー」が出ます。コピーして **Safari** に貼りつけて開き、「カレンダーに追加する」→「すべてを追加」。
  （ホーム画面のアプリからは、カレンダーへ直接ファイルを渡せないことが多いため、このやり方にしています。リンクに入るのはスタート日とお知らせの時刻だけです）
- お知らせが来ないときは：iPhoneの「設定」→「カレンダー」→「通知」がオンになっているか確認してください。

**Android**
- 「カレンダーに追加する」で `asayoru-calendar.ics` が保存されます。ダウンロードの通知や「Files」アプリから開き、カレンダーアプリを選びます（Galaxyのカレンダーなどはそのまま開けます）。
- Googleカレンダーのアプリで開けないときは、パソコンで https://calendar.google.com →（歯車）設定 →「インポート/エクスポート」→ ファイルを選んで取り込みます。
- Googleカレンダーは、取り込んだ予定のお知らせを「カレンダーのデフォルトの通知」にします。そのカレンダーの設定で通知を「0分前」にしておくと、ちょうどの時刻に届きます。

### もっと手軽にしたいとき（予備の方法）
カレンダーアプリで「朝のメニュー」という予定を自分で1つ作り、「繰り返し：毎日」「通知：予定の時刻」にするだけでも確実に届きます（メニュー名は出ませんが、通知からアプリを開けばわかります）。

## 画面のしくみ（2つのタブ）

画面の下で「今日」と「ごはん」を切りかえます。

**今日タブ**：朝・夜の運動メニュー、「今夜のごはん」の1行（タップでごはんタブへ）、連続日数・バッジ・28日カレンダー、体の変化、体重と目標、設定。

**ごはんタブ**（レシピは夜ごはんだけ）
- **今夜のごはん**：アプリのレシピ7品＋味の素パークのレシピ46品の中から、毎日おすすめを1つ出します。夜の目安（約350〜500kcal、ごはん半分・みそ汁こみ）に入るもので、同じ週の中では同じレシピをくり返さず、前の日と主菜（鶏・魚・豚など）を変えます。「ほかのおすすめにする」で次の候補に、「作り方を見る」でレシピのページが開きます（作り方を見るときはネットが必要です）。
- **朝・昼・おやつのコツ**：レシピではなく、そろえたいもの（たんぱく質・主食・野菜）の目安だけ。食事ルールのチェックもここにあります。
- **カロリーを記録する**（ふだんはオフ）：オンにすると、朝・昼・夜・おやつを「軽め／ふつう／多め」のボタン1回で入れられます。
- **1週間の夜ごはん**：7日分の夜ごはんを1日ずつ「変える」から選べます。主菜の種類でしぼりこみ、外食や好きなレシピ（名前・だいたいのカロリー・URL）も入れられます。決めなかった日はおすすめになります。下に、この7日分の夜ごはんの買い物リストがあります。

**カロリーの目安**：「設定 → からだの目標」で年齢を入れると出ます。計算は「基礎代謝（Mifflin-St Jeor式）×1.4 − 400kcal」で、1,200kcalと基礎代謝より下にはしません。夜の目安は、そこから朝 約300・昼 約450・おやつ 約100kcal を引いたものです。

**目標の見える化**：体重カードに、スタート→いま（7日平均）→目標の進み具合のバー、達成率、−1kgごとのバッジ、グラフの目標線と「1週間0.5kg」の目安ペース線が出ます。−1kg進むごとにお祝いが出ます。

> 5kg減らすのは、無理のないペース（1週間に0.4〜0.5kg）だと約10週間（2か月半）が目安です。最初の2〜3週間は水分が抜けて速く減ることが多いので、そのあとペースが落ちても失敗ではありません。

## データの保存とバックアップ

- 記録は**スマホの中（ブラウザの保存領域）だけ**に保存されます。サーバーには送りません。
- 「書き出す」で `asayoru-backup-日付.json` を作れます。iPhoneでは共有画面が出るので「ファイルに保存」やLINE・メールで自分に送って保管してください。
- **機種変更のとき**：古いスマホで「書き出す」→ 新しいスマホでアプリを開いて「読み込む」→ ファイルを選ぶ。
- 月に1回くらい、アプリが「バックアップしておきませんか？」と声をかけます（7回以上記録したあと）。

## 動作の確認（開発用）

パソコンに Node.js が入っていれば、このフォルダで次を実行できます。

```bash
node --test tests/core.test.js
```
日付計算（週・周の切り替わり、連続日数、休む日、おかえり表示）、保存と読み込み、カレンダーファイルの形式、夜ごはんのおすすめ（くり返さない・目安に入る）、カロリーの目安、目標の進み具合を確かめます。

```bash
node tools/check-videos.mjs
```
アプリの ▶ 動画がまだ公開されているかを確かめます。NGが出たら `core.js` の `V` の中のIDを差し替えます。

```bash
node tools/check-recipes.mjs
```
夜ごはんのネットのレシピが、まだ見られるか・カロリーが変わっていないかを確かめます。NGが出たら `recipes.js` からその行を消します。

日付をずらして画面を見たいときは、URLの最後に `?date=2026-11-10` のように付けて開きます（「テスト日付」と黄色く表示されます。ここで押したボタンは本当の記録として保存されるので、試すのは公開前のパソコンだけにしてください）。
